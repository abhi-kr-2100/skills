# abhi-kr-2100's AI Skills Collection

A collection of AI skills designed for use by software engineers.

## Installation

This collection can be installed using [skills.sh](https://github.com/vercel-labs/skills).

### Project-specific Installation

To install these skills for a specific project only, run this in the project directory:

```bash
npx skills add abhi-kr-2100/skills
```

### Installing a Single Skill

To install only one specific skill from this collection, first list the available skills:

```bash
npx skills add abhi-kr-2100/skills --list
```

Then install the specific skill by name using the `--skill` flag:

```bash
npx skills add abhi-kr-2100/skills --skill <skill-name>
```

### Global Installation

To install these skills globally for all projects:

```bash
npx skills add --global abhi-kr-2100/skills
```

### Installing for Specific AI Agents

You can install skills for specific AI agents by specifying the agent name:

```bash
npx skills add abhi-kr-2100/skills --agent <agent-name>
```

Refer to the [skills.sh documentation](https://github.com/vercel-labs/skills) for more details on agent-specific installation and configuration options.
