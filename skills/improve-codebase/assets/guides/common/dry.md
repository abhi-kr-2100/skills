# Don't Repeat Yourself (DRY)

- **Avoid Duplication:** Every piece of knowledge must have a single, unambiguous, authoritative representation within a system.
- **Refactor to Functions/Modules:** If you see the same logic repeated in multiple places, extract it into a common function, method, or class.
- **Data Normalization:** Avoid storing the same data in multiple places. Calculate derived data where possible.
- **Logic Abstraction:** Use loops, map/filter, or other abstractions to handle repetitive operations on data structures.
